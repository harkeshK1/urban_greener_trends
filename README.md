# Urban Greener Trends: Chennai vs Shanghai

This repository contains datasets, maps, code, and results for the project:

**"A Comparative Study of Urban Greenery Trends in Chennai and Shanghai: Analysis, Prediction, and Sustainable Urban Planning Using NDVI and Machine Learning"**

---

## 📊 Overview

This project analyzes urban greenery trends using NDVI (Normalized Difference Vegetation Index) for two major cities:

* Chennai, India
* Shanghai, China

The study combines environmental, climatic, and socio-economic data with machine learning techniques to understand trends and predict future vegetation patterns for sustainable urban planning.

Data (Large Files)

Due to GitHub file size limitations, some large datasets are uploaded separately or in parts.

Datasets include:

* NDVI data (2004–2024)
* Environmental data (temperature, rainfall, air pollution)
* Population and urban expansion data
* Combined and normalized datasets
* Predicted NDVI values (2025–2045)

---

Data Description

* **Type:** Satellite NDVI + environmental + socio-economic data
* **Time Period:** 2004–2024 (historical), 2025–2045 (predictions)
* **Processing Includes:**

  * Data cleaning and normalization
  * Feature integration
  * Machine learning modeling
  * Forecasting future trends

 Methodology

* NDVI trend analysis
